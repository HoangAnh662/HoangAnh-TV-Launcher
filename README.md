# HoangAnh TV Launcher

Launcher nhẹ dành cho Android TV / Google TV, tối ưu điều khiển bằng remote.

## v1.0.0
- Hoạt động như HOME launcher
- Tự quét ứng dụng TV đã cài
- Lưới ứng dụng điều khiển bằng D-pad/remote
- Hiển thị icon và tên ứng dụng
- Đồng hồ và ngày tháng tiếng Việt
- Hiệu ứng focus cho TV
- Android 6.0 (API 23) trở lên

APK được build tự động bằng GitHub Actions.
